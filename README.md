# mariana-legal

Institutional website for **Mariana Advocacia** — a legal consultancy specializing in innovation and positive social impact.

## Objective

The objective of this project is to deliver a professional, accessible web presence for the law firm, providing information about services and enabling clients to get in touch. The site is a static HTML page deployed automatically via GitHub Actions with a custom domain.

## Tech Stack

- HTML5
- GitHub Actions (automated deploy)
- Custom domain via `CNAME`

## Deploy

Pushing to the `main` branch triggers the GitHub Actions workflow (`.github/workflows/deploy.yml`) which publishes the site automatically.
